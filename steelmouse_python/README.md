# SteelMouse (Legacy Python Version)

This directory contains the original Python implementation of SteelMouse using `pystray`, `Pillow`, `hidapi`, and `rivalcfg`.

> [!NOTE]
> The primary, state-of-the-art native version of SteelMouse is now written in **Rust** located at the root of the repository. The Rust version uses ~2.1 MB executable memory and <10 MB RAM.

## Running the Python Version

```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Run the application
python mouse.py
```
